# 評価

スキルを読み込んだエージェントが、スキルの言うとおりに振る舞うかを確かめます。

各判定は`SKILL.md`が求める挙動を1つずつ述べたものなので、判定の失敗はスキルと実際の動作との差を意味します。

## 実行する

1. このリポジトリを読んでいないエージェントに`skills/diataxis/`を読み込ませます。
2. `evals.json`のプロンプトを与えます。`files`に書かれた入力ディレクトリを作業対象にします。
3. 答えを`<runs>/<eval-name>/outputs/answer.md`に保存します。
4. 採点します。

```bash
python3 evals/results/grade.py <runs>
```

結果の置き場は既定で`evals/runs`です。`DIATAXIS_EVAL_RUNS`でも指定できます。

すべての判定が通り、かつすべてのevalに答えがある場合だけ、終了コードが0になります。

## 構成

| ファイル | 内容 |
| --- | --- |
| `evals.json` | プロンプトと、各evalが何を見ているか |
| `fixtures/` | プロンプトが対象とするドキュメントの構成 |
| `results/grade.py` | 判定 |

プロンプト、入力、判定は英語です。

入力はエージェントが分析する対象そのもので、判定はエージェントの答えの文面に正規表現を当てます。翻訳すると測っているものが変わります。

## 判定を書く

モデルが元から持っている知識ではなく、スキルが求める挙動を判定にしてください。

「4つのモードをすべて挙げる」はスキルを読み込まなくても通るので、何も測っていませんし、失敗しようもありません。

判定は正規表現で文面を照合するため、適切な語を並べただけの答えでも通りえます。点数だけでなく、答えそのものも読んでください。
