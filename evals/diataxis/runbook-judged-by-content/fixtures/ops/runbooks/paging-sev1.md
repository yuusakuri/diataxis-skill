# SEV1 paging runbook

Work top to bottom. Do not skip ahead.

## 0–5 minutes
- [ ] Acknowledge the page in the pager.
- [ ] Open the incident channel: `/incident start sev1`.
- [ ] Declare yourself incident commander or hand off explicitly.

## 5–15 minutes
- [ ] Post an initial status to the status page. Use the template; do not
      write prose under pressure.
- [ ] Page the on-call for the affected service from the rota.
- [ ] Start the timeline document. Every action gets a timestamp.

## Every 30 minutes until resolved
- [ ] Update the status page, even when there is nothing new.
- [ ] Confirm the comms lead is still in the channel.

## On resolution
- [ ] Final status page update.
- [ ] Schedule the review within two working days.
- [ ] Hand the timeline to the review facilitator.

Escalation: if no service owner has responded within 15 minutes, page the
engineering manager on the escalation rota, then the director.
