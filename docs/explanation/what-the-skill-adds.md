# このスキルが足すもの

Diátaxisはよく知られた枠組みで、能力のあるモデルは指示されなくても適用します。このスキルの価値は枠組みそのものではなく、次の4つの規則にあります。

## 判断の根拠となった行を示す

「このページは3つの役割を担っています」という指摘は、受け取った側に反論の手がかりを与えません。

このスキルは、判断ごとに根拠となった行を示すことを求めます。「3行目から5行目がExplanation、7行目から10行目が手順、12行目から16行目がReferenceの表です」と示せば、著者は一点ずつ検討できます。

## 体裁を揃えるためのページを作らない

4つのディレクトリを揃えることは目的ではありません。

Diátaxisを適用するよう指示されたモデルは、対応する文書がないモードのディレクトリを作って空のまま残したり、誰も求めていないTutorialを書いたりしがちです。空のディレクトリは、存在しない文書があるように見せます。

このスキルは、あるモードが無いことを、それを必要とする読者がいるときだけ不足として扱います。不足していると判断したときも、勝手に書くのではなく、その読者が何を求めて来るはずかを伝えます。

## モードとディレクトリを分けて扱う

Diátaxisを適用するよう指示されたモデルは、4つのモードをそのままディレクトリ名にして、既存のページを全部そこへ動かそうとします。

このスキルは、既存の情報設計を優先します。モードごとのディレクトリ構成は、既存の構造がないドキュメントでの候補の1つとして示します。

## 形式が別に決まっている文書に手を出さない

Diátaxisは読者のために書かれたドキュメントを整理する枠組みです。

別の仕様や形式によって構造が定義されている成果物は、その形を読者ニーズではない要求が決めています。4つのモードに合わせて書き換えると、その文書を役立たせている構造が失われます。

このスキルは、そうした成果物をDiátaxisに合わせる目的だけで書き換えません。
