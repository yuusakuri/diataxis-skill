# なぜDiátaxisなのか

ドキュメントが使いにくいとき、原因は文章そのものにないことがほとんどです。文は読みやすく事実も正確なのに、読者は探しに来たものを見つけられません。

原因は、1つのページが複数の読者を同時に相手にしていることにあります。

「キャッシュ」という名前のページには、キャッシュに関するあらゆる内容が集まります。なぜキャッシュを使うのか、どう有効にするのか、どんなオプションがあるのか、初めて使う人が何から始めればよいのか。4種類の読者が訪れ、それぞれが自分に関係のない3種類の内容を読み飛ばすことになります。

## 2つの問いで分ける

Diátaxisは、読者がそのページを開いた時点の状況を2つの問いで整理します。

1. その内容は行動を扱うのか、認識を扱うのか。
2. 学んでいる読者に応えるのか、作業している読者に応えるのか。

答えの組み合わせで、4つのモードが決まります。

| 内容が扱うもの | 読者の状況 | モード |
| --- | --- | --- |
| 行動 | 学んでいる | Tutorial |
| 行動 | 作業している | How-to guide |
| 認識 | 作業している | Reference |
| 認識 | 学んでいる | Explanation |

どちらの問いも、扱う主題ではなく読者について尋ねています。「キャッシュ」は主題なので4つのモードすべてにまたがります。主題ごとにファイルを作ると内容が1か所に集まってしまうのは、このためです。

## この分け方が機能する理由

1つは、どのモードなのかを決められることです。2つの問いにそれぞれ2つの答えがあるだけなので、ほとんどの内容は議論の余地なくどれか1つに収まります。

もう1つは、混ざっている状態を外から見分けられることです。モードごとに書き方が違うので、読めば気づけます。手順が書かれたReference、番号付きリストで終わるExplanationがその例で、このスキルが探しているのもこうしたページです。
